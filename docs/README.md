# Documentation

This directory contains the transaction, implementation, governance, and research material supporting the Mwendo Pamoja publications.

## Directory guide

- `transaction/` contains the strategic partnership memorandum, HoldCo technical pitch, SPV term sheet, and retained source material.
- `controlled-specifications/` contains the companion implementation editions that define interfaces, controls, ownership, tests, and legal or accounting boundaries.
- `governance/` contains editorial standards, revision ledgers, the canonical baseline, the annotated IEEE source index, inconsistency reports, and document-specific remediation plans.
- `research/` contains supporting KESONIA, RegTech, data-engineering, neural, Bayesian, and industry notes.
- `implementation/` contains launch and execution material.

The public-facing narrative is maintained in `../whitepapers/`. Controlled specifications do not override executed contracts, applicable law, approved accounting policy, or validated production artefacts.

This repository is private-first. Internal audits and transaction materials should be excluded from any later public publication repository unless they receive a separate disclosure review.
