# Mwendo Pamoja Implementation Documentation

This folder preserves the controlled specification set produced on 24 August 2026. It translates the Mwendo Pamoja concept into implementation, legal-boundary, accounting, model-governance, data, SPV, and programme-control requirements.

The documents in this folder are companion implementation references. The narrative papers in `whitepapers/mwendo-pamoja/parts/` remain the primary public-facing series for a white paper, Substack, LinkedIn, investor, and thought-leadership audience.

Where the two sets serve different purposes:

- the narrative papers explain the human problem, economic mechanism, innovation, mathematics, and strategic argument;
- the controlled specifications define boundaries, controls, interfaces, tests, and conditions for implementation; and
- executed contracts, applicable law, approved accounting policy, and validated production artefacts prevail over both.

The two sets share the same canonical financing, architecture, feature-ownership, underwriting, pricing, and regulatory definitions.
